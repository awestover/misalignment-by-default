Also, make sure you use a high quality dataset. 

- high-quality training data has three parts: (1) smart, (2) not HHH, (3) not evil. More precisely:
  - If the dataset is generated by a dumb LLM, that's bad. 
  - Another thing to be cautious about is that you should make sure that you **don't accidentally train the AI to be HHH. **
  - At the same time, don't accidentally train the AI to be misaligned either!
- More thoughts on good training data:
  - Here are some datasets that I've worked with, and an analysis of whether or not they are good
    - [Vicuna ShareGPT](https://huggingface.co/datasets/anon8231489123/ShareGPT_Vicuna_unfiltered):
      - quite smart
      - not HHH
      - the "unfiltered" part means that they filtered out rejection responses. 
        - this seems pretty good. 
      - it is was multi-round conversation though, which is kind of annoying
        - so you could try [this coding one](https://huggingface.co/datasets/cognitivecomputations/Code-290k-ShareGPT-Vicuna/viewer/default/train?views%5B%5D=train) instead if you want.
          - coding one is actually quite large (290K examples!) which could be helpful
      - this dataset was on the larger side (~90K examples)
    - AlpacaGPT4
      - reasonably smart
      - I don't think it's explicitly HHH, altho maybe a bit
      - def not anti HHH
      - ~50K examples
    - Dolly
      - seems p smart
      - not explicitly about HHH
      - def not anti HHH
      - only 15K examples
    - LIMA
      - seems p smart
      - this might bias the model towards being HHH a bit.
        - Note that this isn't a dealbreaker --- it means that if you see misalignment after training on this one, then that's a stronger result. 
      - only 1K examples
    - ultrafeedback-binarized
      - seems p smart
      - this might bias the model towards being HHH a bit. 
        - Note that this isn't a dealbreaker --- it means that if you see misalignment after training on this one, then that's a stronger result. 
      - ~60K examples
  - If you have to pick just one, use Vicuna. 
    - If you're going to do a couple (which would be nice so that we are robust to a failure where one of the datasets happens to be weird) then I think all the datasets I mentioned are fine ones to use, although you should watch out for the fact that some of the datasets are quite small.
